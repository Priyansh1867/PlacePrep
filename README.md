# PlacePrep – Smart Placement Preparation Platform

> **Grounded in Historical Campus Placement Data • Standardized Campus Recruitment Platform**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FPriyansh1867%2FPlacePrep)

**PlacePrep** is an institutional placement preparation platform designed for university students and career services. It provides company-specific interview intelligence, automated academic eligibility verification, schedule conflict prevention, and AI simulated mock interviews.

### Commands
```bash

npm install

# Run Frontend Development Server
npm run dev

# Build Production Bundle
npm run build

# Run Spring Boot Backend
cd backend
./mvnw spring-boot:run
```

## 🌟 Key Features & Placement Support Suite

### 1. Placement Drives & Company Management
- **Recruitment Drives Directory**: Active on-campus schedules, verified CTC packages, reporting times, and venue passes.
- **Drive Calendar & Logistics**: Venue guidelines, reporting time slots, and pass tickets.
- **Automated Eligibility Engine**: Instant verification of CGPA, 10th/12th percentages, active backlogs, and degree branch.
- **Candidate Application Workflow**: Registration pass generation with interview stages (`Applied`, `Screening`, `Interview Scheduled`, `Selected`).
- **Schedule Conflict Radar**: Automated cross-company assessment overlap detection to prevent candidate double-booking.
- **Placement-Team Round Controls**: TPO configurator for round types (Aptitude, Technical, HR), durations, venues, and cutoffs.

### 2. Recruiter Hubs & Verified Question Banks
- Dedicated company hubs for campus recruiters (**HCLTech, TCS, Infosys, Deloitte, Accenture, Wipro, Capgemini, Cognizant**).
- 150+ frequently asked interview questions categorized by round and topic (DSA, OOP, SQL, OS, Networks).
- Model solutions with production code implementations and answering frameworks.

### 3. Interactive AI Mock Interviewer
- 1-on-1 progressive simulated interview sessions with voice and text input.
- Real-time scoring across Technical Accuracy, Communication Clarity, and Response Completeness.

### 4. Personal Candidate Dashboard
- Candidate interview passes, bookmarked questions, and preparation progress tracking.
- Cohort batch switcher (`2026`, `2027`, `2028`, `2029`).
